Claude Code CLI — Headless Mode (Team Subscription)

Synthesis calls run through the Claude Code CLI installed on the machine hosting this tool, using its own login. No API key or token is entered or stored here.

1. Install Claude Code on the machine running this server (see anthropic.com/claude-code).
2. In a terminal, run claude and log in (/login) with your Claude Team account.
3. Click "Check Claude CLI" to verify the CLI is found.
4. Click "Apply / Login". Leave Model blank to use the CLI's default.

Usage counts against your own Team seat's limits (shared with your interactive Claude Code use). If a call fails with a login error, re-run claude in a terminal and log in again.
Grok CLI — Headless Mode (SuperGrok / X Premium+ Subscription)

Synthesis calls run through the local grok CLI using its OAuth login. No xAI API key is entered here.

1. Ensure the grok CLI is installed (commonly at ~/.grok/bin/grok).
2. In a terminal run grok login --oauth (or grok login) and complete the browser OAuth with your subscription account.
3. Click "Check Grok CLI" to verify.
4. Select the option and click "Apply / Login". Leave Model blank for CLI default.

Usage counts against your SuperGrok / X Premium+ subscription.
